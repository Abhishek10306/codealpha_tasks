# CodeAlpha C++ Programming Internship Tasks

This repository contains the C++ programming tasks completed as part of the **CodeAlpha C++ Programming Internship**.

## 👨‍💻 Tasks Completed

### Task 1 — CGPA Calculator

A C++ based CGPA calculator that calculates semester GPA and overall CGPA using course credits and grade points.

**Concepts Used:**
- C++ classes and functions
- Vectors
- Input validation
- Grade-point calculation
- Weighted average
- CGPA calculation

**Website:** Responsive HTML, CSS and JavaScript interface for entering courses and calculating GPA/CGPA.

---

### Task 2 — Login and Registration System

A secure educational login and registration system implemented using C++.

**Features:**
- User registration
- Username validation
- Duplicate username detection
- Password validation
- Password hashing using SHA-256
- Random salt generation
- Login authentication
- File-based credential storage

**Concepts Used:**
- File handling
- Functions
- Classes
- String processing
- SHA-256 hashing
- Input validation

**Note:** This project is intended for educational purposes. Production authentication systems should use established password-hashing libraries such as Argon2, bcrypt or scrypt.

---

### Task 3 — Sudoku Solver

A C++ Sudoku solver using a recursive **backtracking algorithm**.

**Features:**
- 9×9 Sudoku grid
- Input validation
- Row checking
- Column checking
- 3×3 subgrid checking
- Recursive backtracking
- Automatic solution generation

**Concepts Used:**
- 2D arrays
- Recursion
- Backtracking
- Functions
- Object-oriented programming

**Website:** Interactive Sudoku grid for entering and solving puzzles.

---

### Task 4 — Banking System

A console-based banking management system developed using object-oriented C++.

**Features:**
- Create customers
- Create bank accounts
- Deposit money
- Withdraw money
- Transfer funds
- View account information
- View transaction history
- Balance management
- Input validation

**Classes Used:**
- `Customer`
- `Account`
- `Transaction`
- `BankingSystem`

**Concepts Used:**
- Object-oriented programming
- Classes and objects
- Encapsulation
- Vectors
- Functions
- Transaction management
- Input validation

**Website:** Modern responsive banking dashboard demonstrating account information, deposits, withdrawals, transfers and transaction history.
