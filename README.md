# CodeAlpha C++ Programming Internship Tasks

This repository contains the C++ programming tasks completed as part of the **CodeAlpha C++ Programming Internship**.

## 👨‍💻 Tasks Completed

### Task 1 — CGPA Calculator

A C++ based CGPA calculator that calculates semester GPA and overall CGPA using course credits and grade points.

**Features:**
- Course and credit input
- Grade point calculation
- Semester GPA calculation
- Overall CGPA calculation
- Input validation

**Concepts Used:**
- C++ functions
- Vectors
- Input validation
- Weighted average
- CGPA calculation

---

### Task 2 — Login and Registration System

A C++ login and registration system with file-based credential storage.

**Features:**
- User registration
- Username validation
- Duplicate username detection
- Password validation
- Password hashing
- Salt generation
- Login authentication
- File-based storage

**Concepts Used:**
- File handling
- Functions
- Classes
- String processing
- SHA-256 hashing
- Input validation

> **Note:** This project is intended for educational purposes. Production authentication systems should use established password-hashing libraries such as Argon2, bcrypt or scrypt.

---

### Task 3 — Sudoku Solver

A C++ Sudoku solver using a recursive **backtracking algorithm**.

**Features:**
- 9×9 Sudoku grid
- Input validation
- Row checking
- Column checking
- 3×3 subgrid checking
- Recursive backtracking
- Automatic solution generation

**Concepts Used:**
- 2D arrays
- Recursion
- Backtracking
- Functions
- Object-oriented programming

---

### Task 4 — Banking System

A console-based banking management system developed using object-oriented C++.

**Features:**
- Create customers
- Create bank accounts
- Deposit money
- Withdraw money
- Transfer funds
- View account information
- View transaction history
- Balance management
- Input validation

**Classes Used:**
- `Customer`
- `Account`
- `Transaction`
- `BankingSystem`

**Concepts Used:**
- Object-oriented programming
- Classes and objects
- Encapsulation
- Vectors
- Functions
- Transaction management
- Input validation
